# 设计系统 · 简页

> 目标：一套「纸与墨」的阅读器界面 —— 让界面退到字后面，但不至于寡淡到没有识别度。
> 所有取值都在代码里（`ui/theme/ThemeTokens.kt`、`ui/theme/PlainPageTextStyles.kt`），
> 本文只解释**为什么这样定**，改值请连同 `ThemeTokensTest` 一起改。

## 1. 取向

三个判断决定了整套视觉：

1. **这是读书的地方，不是信息流。** 屏幕上最该显眼的是正文和书名，所以没有卡片阴影、没有大面积色块、没有圆角药丸按钮。结构靠留白、发丝线和字号层级区分。
2. **器物要退，内容要进。** 顶栏/底栏/导航和纸面同色，只用一条发丝线把"器具"和"内容"分开；分隔线对比度刻意压到约 1.3:1，只负责"暗示这里分开了"。
3. **颜色只做印章。** 强调色（松烟绿）只出现在可点的字、当前选中、读到哪儿的进度线上。铺成背景就变成另一个 App 了。

## 2. 配色（三主题，同一套语义名）

| 语义 | 浅色 | 深色 | 护眼 | 用途 |
|---|---|---|---|---|
| `paper` | `#FDFBF7` 米白纸 | `#121110` 暖黑 | `#F6ECD6` 旧纸黄 | 阅读页、列表底 |
| `surface` | `#F6F2E9` | `#1B1A17` | `#EFE2C6` | 备用面板色（当前栏位用 `paper` + 发丝线区分，不叠两层底色） |
| `textPrimary` | `#17150F` | `#EAE5DA` | `#33291B` | 书名、正文 |
| `textSecondary` | `#5C574D` | `#9C968A` | `#6A5A43` | 元信息、未选中的选项 |
| `accent` | `#2F5D50` 松烟绿 | `#8FBFA9` | `#8A5526` 赭石 | 进度、选中、可点文字 |
| `divider` | `#E4DED2` | `#2B2925` | `#DCCCB0` | 发丝线 |
| `coverWash` | `#EFE9DC` | `#23211D` | `#EADFC4` | 封面底纹 |

约束（`ThemeTokensTest` 守着）：

- 正文/纸面 ≥ 7:1（浅色与护眼），深色 ≥ 4.5:1；次级文字 ≥ 4.5:1。
- 强调色与纸面 ≥ 3:1（它承担"可点"的语义）。
- 深色主题不用纯黑：纯黑配暖字会显得发青、边缘发硬。

## 3. 字体与字阶

两种字族分工，界面里不出现第三种：

- **系统黑体**：书名、栏目、按钮、目录 —— 信息密度高、笔画清楚。
- **系统衬线**：正文、空状态标题 —— 长文更省眼，也把"这是书"这件事说清楚。

| 角色 | 字号 / 行高 | 字距 | 说明 |
|---|---|---|---|
| `brand`（简页） | 22 / — | 4sp | 品牌字，只有一处 |
| `kicker`（离线书架 · 4 本） | 11 / — | 1.6sp | 定位信息：小、疏、淡 |
| `screenTitle` | 15 / — | 0.6sp | 栏目标题、可点文字 |
| `bookTitle` | 16 / 23 | 0.2sp | 列表书名 |
| `bookTitleCompact` | 14 / 20 | 0.2sp | 网格书名 |
| `meta` | 12 / 17 | 0.25sp | 格式 · 体积 · 时间 |
| `progress` | 11 / — | 0.8sp | 强调色进度文字 |
| `readingBody` | 17.5 / 33 | 0.3sp | 正文，两端对齐，`LineBreak.Paragraph` |
| `pageFooter` | 12 / — | 1.1sp | 翻页条 |
| `tocTitle` / `tocChapter` / `tocPage` | 16 / 15 / 11 | — | 目录三级 |
| `emptyTitle` / `emptyHint` | 20 / 13 | — | 空状态 |

正文排版细节：

- **段首缩进两个全角空格**，由 `ReaderScreen` 在渲染前按行补 `　　`（Compose 的 `textIndent` 只作用于整块文本）。短行（≤ 24 字，章节标题/署名/诗句）不缩进 —— 这是个启发式，够用且不易出错。
- `includeFontPadding = false`：关掉旧版字形额外留白，中英文混排的基线更稳。

## 4. 间距与结构

- 统一基准 **22dp** 的左右留白（`PAGE_MARGIN`），书架、最近、设置、阅读页一致；正文 26dp（比列表略宽一点点，读起来更松）。
- 纵向节奏：区块间距 18–24dp，行内元素 6–12dp。列表行上下 16dp。
- 底部导航是一行**字**：`书架 / 最近 / 设置`，选中态 = 强调色 + 16dp 宽的 2dp 墨线（和书架的进度线同一个语汇）。不用图标 —— 只有三个去处、都是文字语义，加图标只是多一层噪音。

## 5. 组件规则

| 组件 | 做法 | 为什么 |
|---|---|---|
| 书架行 | 46×62 封面 + 书名 + 元信息 + （进度文字或进度线）+ `⋯` 菜单 | 长书名最多两行、`⋯` 不抢视线、删除折叠进菜单 |
| 封面占位 | 纸色底纹 + 左书脊线 + 内框 + 首二字淡墨 + 格式小字 | 没有真封面时，也要像"一本书"而不是灰色方块；四档深浅由书名哈希决定，稳定不刺眼 |
| 进度 | TXT 有真·全文比例 → 画 2dp 墨线；EPUB/PDF 分母未知 → 留白 | 宁可留白，也不画一条会骗人的进度条 |
| 导入入口 | 页眉右侧「导入」+ 空状态里一个描边按钮 | 不用浮动按钮：书架的手势空间要留给书 |
| 选项（设置） | 字 + 下划线，选中为强调色 | 纸面上没有凸起的按钮，只有被划出来的一行字 |
| 空状态 | kicker + 短横线 + 衬线标题 + 一句说明 + 主操作 | 三行之内说完，不堆插画 |

## 6. 可切换 UI 的边界

- **主题**：`ThemeTokensCatalog.of(theme)` → `PlainPageTheme` → `LocalThemeTokens`。业务代码只读语义名，不写色值、不判断 `isDark`。
- **书架布局**：`ShelfLayout.LIST/GRID` 的分支只出现在 `ShelfScreen` 里；数据、点击、导入回调完全共用。
- **翻页方式**：`ReadingMode.PAGED/SCROLL` 属于阅读页内部策略，不进 Repository。
- **字号/行距/边距/对齐**：`PlainPageTextStyles` 已预留 `readingBody`（字号、行高、对齐、缩进），P1 页面设置直接从这里派生，不需要改阅读页结构。

## 7. 已知取舍

- 汉字字距（`letterSpacing`）只在 UI 文本上用；正文保持 0.3sp，再多会散。
- 深色下 `divider` 对比度约 1.4:1，属于"看得见但不打扰"，不适合当边界线用在需要强区分的场景。
- 首字 monogram 取书名前两个字，纯装饰、不进无障碍树（`Text` 本身不朗读，父级 `clickable` 有完整语义）。
- 截图由 Robolectric 渲染（`GraphicsMode.NATIVE`），字体来自 JDK 自带字体族，与真机系统字体可能有细微差异 —— 视觉验收仍以真机为准。
